AWS

The infrastructure: today and next

Dev today is one CloudFormation stack (projectx-dev): a VPC, an ALB, a private Fargate task, a private encrypted RDS Postgres, a NAT gateway and monitoring. The plan from Session 03 is to build EKS next to it in the same VPC, run the same image against the same database, then move traffic over a little at a time.

Where it stands after Session 10 — the migration has landed: Terraform added two subnets (10.40.32.0/19, 10.40.64.0/19) to the CloudFormation VPC and built the cluster; Helm added Karpenter. Session 09 gave the app a ClusterIP Service and packaged it as a Helm chart. Session 10 installed the AWS Load Balancer Controller and Gateway API, which built an internet-facing ALB, and moved the Route 53 record across. The public hostname now serves from EKS over HTTPS. ECS and its ALB are deliberately left running as the rollback path. The big diagrams are on How Project X Fits Together.

Serving users now (Nadia, CloudFormation)Running, no traffic yet (you, Terraform + Helm)
  • Why users don't notice: same DNS name, same image, same database. Only where the container runs changes.
  • Traffic shift: 1% → 10% → 50% → 100% with a weighted second target group on the ALB (or Route 53 weighted records). To roll back, change the weights.
  • For homework you build all of this in your own AWS account, not the school's. Keep RDS private.

How your PRs get reviewed

  • Since Nov 9 the infra repo has Sheldon, an AI reviewer that runs as a GitHub Action (Claude Sonnet). It checks your PR against the task in class/NN/README.md and asks you one question about a decision you made.
  • It runs when the PR is opened, reopened or marked ready. After you push a fix, comment @sheldon to get a new review.
  • If Sheldon adds the needs-human-review label, a person reviews it. Every Monday a job also picks a few random PRs for a person to review.
  • So write the PR description for a reader: which worker and add-on setup you chose and why, what you wrote yourself, how you checked it, and the cleanup result.
  • Your PR #99 has had several Sheldon rounds. The latest (Nov 14) keeps one ❌ (the part you write yourself) and asks you to answer its questions as replies on the PR, not in the README.
