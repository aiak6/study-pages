Family app in Docker: 3 containers & Compose

Moved the family app from AWS to one VM as 3 containers: database, backend, frontend. First by hand, then with Docker Compose.

Browser ──:80──► fam-frontend (nginx) ──/api/──► fam-backend (:3000) ──► fam-db (MySQL) ──► volume all on one private Docker network
Glance

Key ideas

WordMeaning
ImagePackaged app, built from a Dockerfile with docker build
ContainerA running image (docker run)
NetworkContainers find each other by name (fam-db, fam-backend)
VolumeData survives when a container is deleted
-p 80:80Opens a port to the outside. Only the frontend has it
nginx proxySends /api/ requests to fam-backend:3000
npm ciClean install of the exact package versions
ComposeOne file + docker compose up -d starts everything
Files

The files

backend/Dockerfile

FROM node:20-alpine
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --omit=dev
COPY src ./src
EXPOSE 3000
USER node
CMD ["node", "src/server.js"]

frontend/Dockerfile (Node builds the site, nginx serves it)

FROM node:20-alpine AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:1.27-alpine
COPY nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80

frontend/nginx.conf

server {
  listen 80;
  root /usr/share/nginx/html;
  index index.html;
  location /api/ { proxy_pass http://fam-backend:3000; }
  location / { try_files $uri $uri/ /index.html; }
}

.dockerignore (both folders): node_modules

docker-compose.yml

services:
  fam-db:
    image: mysql:8.0
    container_name: fam-db
    environment:
      MYSQL_ROOT_PASSWORD: rootpw
      MYSQL_DATABASE: famdb
      MYSQL_USER: famadmin
      MYSQL_PASSWORD: localpw
    volumes:
      - fam-db-data:/var/lib/mysql
    restart: unless-stopped

  fam-backend:
    build: ./backend
    container_name: fam-backend
    environment:
      DB_HOST: fam-db
      DB_USER: famadmin
      DB_PASSWORD: localpw
      DB_NAME: famdb
    depends_on:
      - fam-db
    restart: unless-stopped

  fam-frontend:
    build: ./frontend
    container_name: fam-frontend
    ports:
      - "80:80"
    depends_on:
      - fam-backend
    restart: unless-stopped

volumes:
  fam-db-data:
    name: fam-db-data
Daily

Everyday commands

Run inside ~/my-family-project/app.

docker compose up -d --build              # build + start everything
docker compose ps                         # what's running
docker compose logs -f fam-backend        # logs
docker compose up -d --build fam-backend  # after a code change
docker compose exec fam-db mysql -ufamadmin -plocalpw famdb   # SQL prompt
docker compose down                       # remove containers (data stays)
docker compose down -v                    # also deletes the data!
Gotchas
  • No such container: run the container before checking its logs.
  • Heredoc stuck at >: the paste added spaces before EOF. Use vi instead.
  • YAML needs exact spaces (2 per level, no tabs). Check with docker compose config --quiet.
  • Start the backend before the frontend, or nginx can't find fam-backend.
